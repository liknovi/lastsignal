# Последний сигнал — спецификация релиза 1.0.0

Этот проект доведён до автономной браузерной визуальной новеллы. Исходная концепция, сюжетная библия, ресурсы и релизные решения описаны в `docs/SCENARIO_AND_BIBLE.md`, `docs/ART_DIRECTION.md` и `docs/BUILD_CHECKLIST.md`.

## Реализованная архитектура

- `index.html`, `styles.css` — адаптивный интерфейс.
- `src/story.js` — сценарные данные, сцены, выборы, варианты реплик, персонажи и концовки.
- `src/engine.js` — навигация, характеристики, флаги, сохранения, музыка и модальные экраны.
- `assets/` — локальные SVG-иллюстрации, портреты, музыка.
- `manifest.webmanifest`, `sw.js` — PWA и кеширование.

## Принципы

- Все пути относительные, проект пригоден для GitHub Pages.
- Никаких backend, API-ключей, платных зависимостей или внешних игровых библиотек.
- Сценарий не доверяет пользовательскому вводу как HTML: реплики показываются через `textContent`.
- Все варианты финала доступны из финального выбора.
- Сохранения экспортируются и импортируются в JSON.

## Сборка и публикация

Открыть `index.html` напрямую либо запустить `python3 -m http.server 8000` и перейти на `http://localhost:8000`. Для GitHub Pages загрузить содержимое папки в корень ветки `main`, затем выбрать Settings → Pages → Deploy from a branch → `main` → `/(root)`.
