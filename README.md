# ПОСЛЕДНИЙ СИГНАЛ

**Релизная версия 1.1.0 — Art Edition** — автономная браузерная визуальная новелла на русском языке. Шесть глав, 72 сцены, около 10 100 слов сценария, 166 вариантов выбора и три финала. Игра не использует сервер, платные API или внешние игровые библиотеки.

## Что реализовано

- Главное меню, продолжение игры и выбор открытых глав.
- 6 сюжетных глав и 3 финала: «Новый рассвет», «Цена спасения», «Эхо человечества».
- 72 сцены с диалогами, отдельными страницами текста и выбором действий.
- 166 вариантов выбора. Решения меняют показатели, сохраняемые флаги и дополнительные реплики.
- Четыре показателя: близость, доверие, решимость и ресурсы.
- Отложенные последствия, дополнительные реплики и персональные эпилоги.
- Автосохранение, 3 ручных слота, экспорт и импорт сохранений в JSON.
- История диалогов, быстрое пропускание текущего текста и авточтение с остановкой перед выбором.
- Галерея из 28 сюжетных иллюстраций, открываемых по мере прохождения.
- Профили пяти персонажей.
- Настройки музыки, громкости, размера текста, авточтения и анимации.
- 18 полноцветных кинематографичных фоновых изображений, 5 PNG-портретов персонажей с прозрачностью и 28 иллюстраций галереи (одна концовка использует повторный кадр из-за отсутствующего исходника).
- 6 полноценных музыкальных композиций в MP3: меню, напряжение, хоррор, убежище, романтика и финал.
- Адаптация под десктоп, планшет и телефон.
- PWA/service worker для повторного запуска без сети после первой загрузки.

## Быстрый запуск на Mac

### Вариант 1 — открыть файл

1. Распакуйте архив.
2. Откройте `index.html` в Safari, Chrome или Firefox.
3. Нажмите «Новая игра».

Игра использует `localStorage`, поэтому сохранения останутся в том же браузере и профиле. Для работы музыки браузер может потребовать первый клик по экрану.

### Вариант 2 — локальный сервер (лучше для PWA)

Откройте Terminal, перейдите в папку проекта и выполните:

```bash
python3 -m http.server 8000
```

Затем откройте в браузере:

```text
http://localhost:8000
```

Остановить сервер можно сочетанием `Control + C` в Terminal.

## Публикация на GitHub Pages

1. Создайте новый публичный или приватный GitHub-репозиторий.
2. Загрузите **содержимое этой папки** в корень ветки `main` (файл `index.html` должен лежать в корне).
3. Откройте `Settings → Pages`.
4. В блоке `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/(root)`, нажмите `Save`.
6. После публикации откройте ссылку, которую покажет GitHub Pages.

Все ссылки на сценарий, стили, музыку и изображения относительные. Сборка не требует Node.js, npm, backend или ключей доступа. Файл `.nojekyll` уже включён.

## Сохранения и приватность

Прогресс хранится локально в браузере: автосохранение — отдельно, ручные слоты — отдельно. Очистка данных сайта или смена браузера может удалить локальные сохранения. Для переноса используйте `Настройки → Экспортировать сохранение`, а на другом устройстве — `Импортировать сохранение`.

Игра не отправляет данные на внешние серверы. Музыка и графика загружаются из файлов проекта.

## Структура проекта

```text
index.html                 интерфейс игры
styles.css                 оформление и адаптивная сетка
manifest.webmanifest       PWA-манифест

```

## Проверки перед публикацией

- JavaScript проверен на синтаксические ошибки.
- Проверены ссылки всех сцен на следующие сцены и все три финала.
- Проверены локальные ссылки на фоны, портреты, CG и музыку.
- Проверено число глав, сцен, выборов и объём сценария.
- Файлы не используют абсолютные пути, зависящие от домена.

В этой сборке установлены реальные изображения из пользовательского архива. Портреты персонажей сохранены как PNG с альфа-каналом; фоны и CG — JPEG. Музыка встроена из шести предоставленных MP3-композиций. Файл `docs/ASSET_IMPORT_LOG.csv` фиксирует порядок и соответствие 44 изображений, назначенных по временным меткам ZIP. Одно изображение для концовки «Цена спасения» отсутствовало: для этой карточки галереи временно повторно используется кадр `final_promise.jpg`; остальные 27 CG уникальны.


## Release 1.1.1 — сюжетные иллюстрации
Все сцены и финалы, у которых в сценарии задано поле `cg`, теперь показывают соответствующую полноэкранную иллюстрацию непосредственно во время повествования. CG остаётся видимой на протяжении сцены; сцены без CG продолжают использовать фон и спрайт персонажа.
