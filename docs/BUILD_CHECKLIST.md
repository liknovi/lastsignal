## Известные ограничения

- В архиве не было фото-референса Виты. Портрет выполнен по текстовому описанию сценарной библии.
- Иллюстрации выполнены в оригинальной векторной стилизации; это не фотореалистичный коммерческий арт.
- Сохранения браузерные. Для переноса между устройствами используется экспорт/импорт JSON.
- Автономная PWA-установка и service worker активируются при запуске через HTTP(S), например через GitHub Pages или локальный сервер. При открытии `index.html` напрямую игра тоже работает, но офлайн-кеш браузера не устанавливается.
